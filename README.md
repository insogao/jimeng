# Jimeng / Dreamina 批量生成插件

支持 Jimeng (即梦) 和 Dreamina AI 图片批量生成的浏览器插件。

## 功能特性

- ✅ 单次生成图片
- ✅ 批量生成（JSON 文件上传 / 粘贴 JSON）
- ✅ 断点续传（刷新后继续未完成的任务）
- ✅ 后台自动轮询结果
- ✅ 图片自动下载（支持多种下载模式）
- ✅ API 控制面板（完整的批量任务管理界面）
- ✅ 批量下载打包（生成HTML下载页面）

## 最近更新 (v1.1)

### 新增功能
1. **API 控制面板** - 完整的批量任务管理界面
   - 拖拽/粘贴 JSON 导入任务
   - 实时状态监控（待处理/进行中/已完成/失败）
   - 任务队列可视化
   - 运行日志实时显示

3. **断点续传**
   - 刷新页面后自动恢复未完成的任务
   - 重新打开插件可继续下载

4. **批量下载**
   - 逐个自动下载
   - 打包生成HTML下载页面

## 安装

1. 下载本代码
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启右上角"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `jimeng` 文件夹

## 使用方式

### 方式 1：Popup 快速生成（适合单张或少量）
1. 点击浏览器工具栏的插件图标
2. 选择方式：
   - **单张生成**：在 "Single Prompt" 输入框输入描述，点击 "Generate Image"
   - **批量生成**：
     - 上传 JSON 文件，或
     - 粘贴 JSON 内容到文本框，点击 "Parse JSON"
     - 点击 "Start Batch (N)"
3. 等待生成完成

### 方式 2：API 控制面板（推荐批量任务）
1. 点击插件图标 → "⚙️ 打开 API 控制面板"
2. 导入任务：
   - 拖拽 JSON 文件到导入区域
   - 或直接粘贴 JSON 内容
3. 设置参数：
   - **模型**：Jimeng 4.5 / 4.1 / 4.0 / 3.0
   - **比例**：16:9 / 9:16 / 1:1 / 4:3 / 3:4
   - **间隔时间**：每个请求之间的等待时间（秒）
   - **下载方式**：
     - 仅生成，完成后手动下载（推荐）
     - 自动下载到默认目录
     - 每次手动选择目录
4. 点击"开始处理"
5. 等待全部完成后，点击"📦 打包下载全部"
6. 选择：
   - **下载为ZIP** - 生成HTML页面，打开后可一键下载全部
   - **逐个下载** - 自动逐个下载所有图片

## JSON 文件格式

```json
{
  "metadata": {
    "title": "任务名称"
  },
  "items": {
    "scene1": {
      "name": "提示词名称",
      "prompt": "详细的图片描述..."
    },
    "scene2": {
      "name": "另一个提示词", 
      "prompt": "另一个描述..."
    }
  }
}
```

插件会自动递归遍历 JSON 中所有包含 `prompt` 字段的对象。

## 图片下载位置

根据设置的下载方式：

### 方式 A：自动下载
```
浏览器下载目录/jimeng/<提示词名称>/<时间戳>.png
```

### 方式 B：打包下载
生成一个 HTML 文件，打开后可以：
- 一键下载全部图片
- 右键点击图片 → "图片另存为"
- 打开原图链接

## 注意事项

- **浏览器必须保持打开**：生成过程中请不要关闭浏览器
- **首次使用需要登录**：确保已在 Jimeng/Dreamina 网站登录账号
- **下载目录**：可在 Chrome 设置 → 下载内容 中更改默认下载位置
- **批量任务间隔**：建议保持 1 秒间隔，避免触发频率限制

## 故障排除

### 图片没有自动下载
- 检查浏览器下载设置
- 尝试切换到"仅生成，完成后手动下载"模式
- 使用"打包下载"功能

### 任务卡住或中断
- 刷新页面后会自动恢复
- 点击"暂停"然后"继续处理"

### 下载失败
- 插件会自动回退到手动下载模式
- 会打开新的标签页显示所有图片链接
- 可以右键"图片另存为"手动保存

## Python 辅助脚本

```bash
python api_client.py your_prompts.json --model jimeng-4.5 --ratio 16:9
```

生成导入文件，拖拽到控制面板即可。
